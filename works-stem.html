國中數學視覺化 試玩 → 05 數學幾何教材 App

幾何單元的互動操作教材。

數學幾何 試玩 → 06 心臟解剖生理學俄羅斯方塊對戰

Firebase 房間制的雙人教學遊戲。學生各自用平板加入同一房間，畫面互不干擾；一方消除一排方塊，系統就派三題心臟解剖生理學國考型單選題給對手。

護理教育Firebase對戰機制 GitHub → 07 量子糾纏模擬

把量子糾纏的行為做成可以動手調參數的模擬。

物理模擬 試玩 → 08 時間大冒險

三年級數學時間單元的闖關平台。四關分別練 12／24 時制互換、一分鐘的量感、時分秒化聚與時間單位判斷，另附一個互動撥鐘教具。撥鐘區的時針與分針可各自單獨拖動，拖分針不會連動時針，但時針仍依分鐘落在兩個數字之間；含自由撥鐘、挑戰、經過時間與分數填色四種模式。

國小數學互動教具 試玩 → 09 焙度實驗室

以烘焙曲線為材料的探究學習頁。學生控制溫度探針、逐分鐘記錄豆溫、標記事件，在同一張圖上看曲線怎麼隨操作改變，再回答「曲線從哪裡開始改變」並寫下觀察筆記。
