Software & Platforms軟體與平台

十六套為了解決手上真實問題而開發的系統。八套用於研究與分析，其中三套是供語言模型呼叫的分析伺服器；四套部署在教學與研習現場；四套是研究以外的專案。

Research & Analysis研究與分析

S01 Knowledge Forum 協作知識翻新平台專頁

知識翻新十二原則長年停在質性詮釋，很難在社群運作中即時檢核。這套平台把每一條原則對應到一個可計算的數字，社群跑到一半就看得出哪一條原則還沒發生。已用於築師 2.0 教師社群，累積 260 則筆記、166 次 build-on、998 次閱讀事件。

知識翻新教師社群研究資料匯出 看詳細與圖表 → S02 PISA 量尺與誤差分析平台

PISA 2015 到 2022 的分析平台。這份資料有兩處容易做錯而且錯了不會報錯：學生能力不是實測值而是十個合理推估值，只取一個或先平均都會遺漏推估變異；跨輪次比較還必須計入量尺連結誤差。本專案實測 396 組跨輪比較，其中 16 組忽略連結誤差就會把不顯著判成顯著，標準誤最多被低估至 2.44 倍。涵蓋 98 個國家與經濟體、1,745,082 名學生，原始 SPSS 檔約 6 GB 轉為 632 MB Parquet 並以 DuckDB 建倉，產出圖表與 APA 第七版報告。

S03 journalmap未發布

以 Python 做文獻計量映射：共同作者、關鍵詞共現、直接引用、書目耦合與共被引網絡。演算法不是包裝 VOSviewer，而是從反編譯的 VOSviewer 1.6.21 與它內含的 nl.cwts.networkanalysis 逐一移植，包含 VOS 梯度下降布局、smart-local-moving 的 Leiden 分群、四種邊權正規化、名詞片語抽取、密度場與 Lab 色階，輸出也寫回 VOSviewer 自己的檔案格式，刻意不同之處都在註解裡標明。改用程式介面是為了掃描門檻值、批次產圖與在筆記本裡執行；另外會回報參考文獻的比對率，這個數字決定一張引用圖有沒有意義，桌面版不會顯示。

S04 國內外期刊投稿格式平台

52 本 TSSCI 與 SSCI 期刊的投稿格式速查。字數上限、摘要規定、參考文獻體例、審查流程與費用集中在一頁，可依索引分級或學科領域篩選，可並排比較，也能依選定的期刊產生投稿前檢查清單。單一 HTML 檔，沒有相依套件，下載就能離線使用，另附列印樣式。

學術寫作TSSCI單檔 HTML 開啟 → S05 訪談系統需登入

給質性研究團隊的訪談工具，從一份訪談大綱一路做到可以進編碼軟體的逐字稿。研究者把大綱貼進後台，系統依語意拆成題幹、訪談者提示、追問句與預估時間，再自行改寫與排序；訪談當天開現場模式，螢幕一次只放大一題，受訪者說話的同時瀏覽器把語音轉成文字，訪談者當場改錯字，提示與追問句收在旁邊受訪者看不到。結束後匯出成 Markdown、純文字、CSV 或 JSON。資料存在研究團隊自己的 Firestore，沒有中介伺服器。

質性研究語音轉文字Next.js 開啟 → S06 r-stats-mcpMIT

讓語言模型直接使用 R 的統計工具：假設檢定、迴歸、心理計量、存活分析、時間序列與繪圖。32 個結構化工具共用同一個持續運作的 R 工作階段，資料載入一次後續都看得到。輸出是給人讀的表格，檢定假設不成立時會直接說明該改用哪個方法：Levene 檢定顯著就指向 Welch，期望次數過稀就自動改走 Fisher 精確檢定。

MCPRPython32 tools GitHub → S07 ena-mcp開源

認知網絡分析（Epistemic Network Analysis）的 MCP 伺服器，接 webENA 雲端服務。模型由 rENA 後端計算，數值與官方一致。支援跑模型、繪製網絡圖、組間比較與相減網絡、視窗長度掃描，讓質性編碼到網絡分析的流程接得起來。

MCPENA質性分析 GitHub → S08 mplus-mcpMIT

Mplus 的 MCP 伺服器。它的輸出是幾百行定寬文字，要查一個適配度指標得自己翻。這套把整段流程接起來：CSV、Excel、SPSS、Stata 轉成 .dat 並產生 VARIABLE 區塊，依模型類型生成語法（CFA、EFA、路徑分析、SEM、中介、成長模型、LPA、LCA、恆等性、二層），執行後把適配度、估計值與警告讀回成表格，也能並列比較多個模型並做量尺化卡方差異檢定。十個工具，Python 撰寫，授權版與 Demo 版執行檔都能用。

Classroom & Workshop教學與研習現場

S09 數位觀議課系統本機版

觀課時按鈕標記事件，全部對齊課堂時間軸；觀課結束由 AI 產出議課報告，含課堂流程摘要、教學亮點、具體建議與時間分配分析。議課因此從印象式回饋轉為看得到證據的討論。內建學習共同體四層次八指標範本，觀察焦點也可自訂。改編自國立臺灣師範大學張民杰教授團隊的通用時間線標記數位觀課工具，依創用 CC 授權並於系統內標示出處。

S10 IRS 互動教學平台macOS App

課堂即時反饋系統。教師端是 macOS 桌面程式，學生用手機瀏覽器掃 QR code 加入，兩邊都不必安裝任何應用程式。含白板與教具箱、計時器與記分板、學生作品收集與並列比較、全螢幕標註、課後報告匯出，另有中繼伺服器支援跨網路授課。Electron 與 TypeScript 撰寫，67 項自動化測試，可打包成 dmg 分享。

課堂互動ElectronTypeScript
S11 研習站未公開

講師外出分享時的隨身場次網站。開一場研習，系統給一組六碼與 QR code 放進簡報首頁；學員掃碼進手機頁面，取簡報、匿名提問、即時投票、簽到與課後回饋都在同一個網址完成，不必註冊也不必安裝。講師端即時看到誰進來、誰在問、票投成什麼樣，散場前匯出 CSV 交給主辦單位。三種畫面分別對應講師後台、投影幕與學員手機。靜態單頁應用直接對 Firebase 說話，沒有自架伺服器，權限全交給安全規則。

Beyond Research研究以外

S13 親師生平台未公開

家教學生管理系統，老師、家長、學生三種身分皆可登入。含學生資料、課程行事曆與排課、上課紀錄與出缺勤、成績追蹤、學費收費狀態、師長訊息聯絡與教材檔案上傳。Next.js 搭配 Supabase，權限以資料列層級安全性控制。

S14 Caffee 烘豆紀錄與曲線分析

自家烘焙咖啡店的線上平台，核心是烘豆紀錄系統。生豆批次記錄含水率、密度、水活性與篩目，這些數字決定入豆溫與前段火力；即時控制台邊烘邊記，火力與風門的每次調整都留下時間點；曲線分析以滑動視窗最小平方法回歸算升溫率，拆解乾燥、梅納與發展三階段，計算發展率與蓄熱量，並自動偵測升溫率崩塌、回彈與梅納期停滯。最多六爐疊圖，可以一爆對齊比較發展期的斜率差異。另含 SCA 杯測表與 CSV 匯出。

S16 1728 站牌

亞聯客運 1728 在清大與龍潭之間的時刻查詢頁。依裝置日期自動選當日班表，倒數下一班發車並每分鐘更新，收班後改顯示明天首班；點任一班次可看它在沿途每一站的時刻。單一 HTML 檔，沒有相依套件。班表擷取自公路局公路客運即時動態資訊網，站間時刻由起點發車時刻加上實測行駛時間推算，新竹端誤差一到兩分鐘，國道段與龍潭端為推估。
