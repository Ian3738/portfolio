自建系統

五套系統，都是為了解決手上真實的研究或教學問題才寫的。三套用於教學與研究現場，兩套是給語言模型使用的分析工具。

S01

Knowledge Forum 協作知識翻新平台

SELF-BUILT

知識翻新十二原則長年停在質性詮釋，很難在社群運作中即時檢核。這套平台把每一條原則對應到一個算得出來的數字。

知識翻新的實證研究長期仰賴多倫多大學開發的 Knowledge Forum，但該平台在國內取得與客製化都不容易，匯出格式也不利於後續的網絡分析。我自己寫了一套，讓教學介入與研究資料蒐集在同一個系統裡完成。

十二原則・比例型指標 築師 2.0　N = 21

五條可用比例表達的原則。原則 2 有 76% 的筆記被別人接著改寫，代表想法在社群裡確實被推進；原則 1 的提問型筆記只有 14%，是下一輪要拉起來的地方。

十二原則・計數型指標 單位不同，不併入同一座標

其餘七條的單位彼此不同（種、則、對、比值），放進同一根座標軸會誤導，因此以讀數並列。

指標同時具備診斷功能。原則 4 實測為 0，明確指出這個社群還沒進到跨想法統整的階段，這項結果已回饋為下一階段的引導策略。這正是原則 9「內嵌的、即時的、變革性的評量」在說的事。

鷹架使用分布 12 種　260 則筆記

鷹架是引導成員以特定認知動作發言的句首提示。分布明顯偏向陳述型（我的想法、新發現），而質疑型的「這個想法解釋不了」只有 3 次，反映社群仍偏向補充而非挑戰。

成員發文量與閱讀量 成員已匿名

每個點是一位成員。發文多的人不一定讀得多，讀得多的人也未必發文，右下與左上兩區都有人，這正是「認知能動性」需要分開量測發文與閱讀的原因。

S02

數位觀議課系統

CLASSROOM ANALYTICS

觀課時按鈕標記事件，全部對齊課堂時間軸；觀課結束由 AI 產出議課報告。議課因此從印象式回饋轉為看得到證據的討論。

觀議課歷來高度仰賴觀課者的臨場詮釋，紀錄品質難以標準化，也不容易累積成可分析的資料。時間線標記加上 AI 輔助分析之後，單次觀課經驗才有機會變成可比較、可追蹤的專業知識。

本系統改編自國立臺灣師範大學張民杰教授團隊的通用時間線標記數位觀課工具（1.1 版，113 年中小學教師專業發展計畫），依創用 CC 授權，並於系統內標示原始出處與計畫團隊。

S03

IRS 互動教學平台

macOS + WEB

課堂即時反饋系統。教師端是 macOS 桌面程式，學生用手機瀏覽器掃 QR code 加入，兩邊都不必安裝任何應用程式。

現行的 IRS 多半要求學生端裝專用 App，macOS 上也少有原生支援。這套的做法是讓老師的 Mac 直接當伺服器，學生手機主動連進來，因此連本機網路權限都不需要。

S04–05

開源分析工具

MCP SERVERS
S04 r-stats-mcpMIT

讓語言模型直接使用 R 的統計工具：假設檢定、迴歸、心理計量、存活分析、時間序列與繪圖。32 個結構化工具共用同一個持續運作的 R 工作階段，資料載入一次後續都看得到；配適好的模型存回工作階段，可以接著診斷、比較、預測。輸出是給人讀的表格，p 值寫成 <.001、效果量附上大小標籤、信賴區間先組好。檢定假設不成立時會直接說明該改用哪個方法：Levene 檢定顯著就指向 Welch，期望次數過稀就自動改走 Fisher 精確檢定。

MCPR 4.0+Python 3.12+32 tools GitHub → S05 ena-mcp開源

認知網絡分析（Epistemic Network Analysis）的 MCP 伺服器，接 webENA 雲端服務。模型由 rENA 後端計算，數值與官方一致。支援跑模型、繪製網絡圖、組間比較與相減網絡、視窗長度掃描，讓質性編碼到網絡分析的流程接得起來。
